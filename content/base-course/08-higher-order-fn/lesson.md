## Log Entry

Личный журнал. Сколько раз я писала одну и ту же рекурсию: пустой список — пустой результат, иначе — обработать голову и повторить для хвоста. Сегодня выяснила, что это редко нужно писать самой: `map` применяет процедуру к каждому элементу и собирает список результатов, `filter` оставляет только элементы, прошедшие проверку, а `foldl` сворачивает список в одно значение, накапливая его слева направо. Втроём они покрывают почти все случаи, для которых раньше требовалась ручная рекурсия по списку.

## Exercise

Определите процедуру `(sum-of-squares lst)`, которая возвращает сумму квадратов всех чисел в списке `lst`, используя `map` и `foldl` (или их эквивалент).

Затем определите `(evens-only lst)`, которая возвращает список только чётных элементов `lst`, используя `filter`.
